## 一、整体请求流（时序）

```
用户输入 "帮我算一下 2 ** 10"
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│ CLI: AgentDemoApp.run()                                      │
│ Web: AgentApp._chat_handler()                                │
│ Eval: Evaluator._evaluate_one()                              │
│                                                              │
│  三者都从同一个地方获取：                                      │
│  system_prompt = from app_core.SYSTEM_PROMPT                 │
│  tool_map = build_tool_map(client, get_rag, ...)            │
│  tool_executor = ToolExecutor(tool_map, policy, confirm)    │
└────────────────────────────┬────────────────────────────────┘
                             │  准备 messages + tools
                             ▼
┌─────────────────────────────────────────────────────────────┐
│ AgentRuntime.run(messages, tools, tool_map, ...)             │
│                                                              │
│  1. skill_registry.match(last_user) → 激活 Skill ？          │
│     ├─ 命中 → 替换 system prompt + 收窄工具集 + 覆盖迭代上限  │
│     └─ 没命中 → 用原始 prompt + 全工具集                      │
│                                                              │
│  2. 循环（for iteration in range(max_iterations)):           │
│     ├─ client.client.chat.completions.create(..., tools=)   │
│     ├─ finish_reason == "tool_calls" → 解析 tool_calls       │
│     │     ├─ ToolExecutor.execute(name, args) → 执行         │
│     │     │     ├─ ToolPolicy.classify(name) → 风险等级       │
│     │     │     ├─ allow_write/allow_execute → 允许？         │
│     │     │     ├─ confirm_write/confirm_execute → 确认？     │
│     │     │     └─ 调用 Python 函数 → 返回结果                │
│     │     └─ 结果 append role="tool" → 下一轮循环             │
│     └─ finish_reason != "tool_calls" → 输出 final → return   │
│                                                              │
│  3. 每次 yield AgentEvent                                    │
│     run_started → route_selected → tool_started              │
│     → tool_finished → observation → final / error            │
└────────────────────────────┬────────────────────────────────┘
                             │  AgentEvent 迭代器
                             ▼
┌────────────────────────────┴────────────────────────────────┐
│                                                              │
│  CLI on_event:   打印 [Tool Call] xxx → [Result] xxx         │
│  Web on_event:   Gradio queue 推 trace_buffer 实时渲染       │
│  Eval on_event:  ToolCallTracker 记录工具调用序列             │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 核心数据流

| 数据 | 从哪来 | 流向谁 |
|------|--------|--------|
| System Prompt | `app_core.build_system_prompt(skill_registry)` | `runtime.run()` → `client.chat` |
| Tool Schemas | `app_core.TOOL_SCHEMAS` + MCP 动态追加 | `runtime.run()` → LLM `tools=` 参数 |
| Tool Map | `app_core.build_tool_map(client, rag, ...)` | `ToolExecutor(tool_map)` → 执行时查名调用 |
| Tool Policy | CLI/Web 各自构造 `ToolPolicy(allow_execute=..., confirm_execute=...)` | `ToolExecutor(policy)` → 执行前判定 |
| AgentEvent | `runtime.run()` yield | CLI/Web/Eval on_event callback |
| SkillDef | `skill_registry.match(last_user)` | `runtime._apply_skill_prompt()` → 激活时替换 system |

## 四、三种运行模式对比

CLI / Web UI / Eval 三种模式**共享同一个 AgentRuntime + 同一个 TOOL_SCHEMAS + 同一个 tool_map 结构**，但 ToolPolicy 和 on_event 回调不同：

| 维度 | CLI (`main.py`) | Web UI (`web_ui.py`) | Eval (`eval.py`) |
|------|-----------------|---------------------|------------------|
| ToolPolicy `allow_execute` | **True**（但每次 confirm） | **False**（默认禁用） | 同 Web UI（False） |
| ToolPolicy `confirm_execute` | **True**（每次 ask y/n） | 不适用 | 不适用 |
| Human Confirm 实现 | `input("确认？")` 同步 | Gradio queue 事件回调 | 跳过（自动 approve） |
| 会话持久化 | ✅ SQLite ChatStore | ❌ per-browser Gradio State | ❌ 临时 TempDir |
| on_event 渲染 | `print` 文本 | Gradio queue 实时 trace | ToolCallTracker 记录轨迹 |
| RAG 初始化 | `rag_directories` 扫描 | 同 CLI | 仅在 TempDir 内 seed 单文件 |
| Skill 路由 | ✅ 开启 | ✅ 开启 | ✅ 开启 |
| MCP | 可选 | 可选（allowlist） | 关闭 |
| 典型启动命令 | `python main.py` | `python -m ai_agent.web_ui` | `python -m ai_agent.eval` |

## 五、关键设计决策速查

| 决策 | 核心代码 | 为什么这么做 |
|------|---------|-------------|
| 单一真相源 | `app_core.py` | CLI/Web UI/Prompt 不再漂移 |
| ToolPolicy 四级风险 | `tooling.py classify()` | 不同 surface 安全策略不同 |
| AgentEvent frozen dataclass | `events.py` | 不可变、顺序保证、安全传递 |
| Markdown Frontmatter Skill | `skill.py _parse_frontmatter()` | 零 PyYAML 依赖 + 非开发者可写 |
| JSON 原子写入 RAG 缓存 | `rag.py _write_cache()` | 防崩溃半写 |
| threading.local Web UI 状态 | `web_ui.py _state_local` | per-tab 隔离 history |
| TempDir 评测隔离 | `eval.py main()` | 用例不互相污染 |

→ 完整 34 条决策见 [设计决策清单](./设计决策清单.md)
